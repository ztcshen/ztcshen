## Selected projects

### [AgentTestBench](https://github.com/ztcshen/agent-testbench)

An API and workflow testing workbench for test engineers and AI agents. It provides APIs to discover runnable targets, execute cases, workflows, and test scenario maps, and retain requests, responses, assertions, and execution results as reviewable records and reports.

- **Focus:** Reusable test assets, workflow regression, and enough failure context for troubleshooting.
- **Stack:** Go, React, TypeScript, with SQLite / PostgreSQL / MySQL support.
- **Explore:** [Documentation](https://github.com/ztcshen/agent-testbench#readme) | [Source](https://github.com/ztcshen/agent-testbench)

### [ER Wiki](https://github.com/ztcshen/er-wiki)

An offline database modeling and ER visualization tool built on drawDB, ELK, libavoid, and other open-source components. It makes complex table relationships easier to read and trace, with local SQL import, model editing, and SVG / PNG export.

- **Focus:** Readable field mappings, relationship routing, and connections across schema domains.
- **Stack:** React, Electron, and JavaScript, with orthogonal layouts and obstacle-aware routing.
- **Explore:** [Live demo](https://ztcshen.github.io/er-wiki/demo.html) | [Documentation](https://github.com/ztcshen/er-wiki#readme) | [Desktop downloads](https://github.com/ztcshen/er-wiki/releases/latest)
